# HuffForge

## Project Overview
A Python-based implementation of Huffman coding for data compression and decompression.

## Project Structure
- `main.py`: Main program and module integration.
- `huffman.py`: Frequency analysis, probability handling, and Huffman tree construction.
- `compression.py`: Text encoding and binary file generation.
- `decompression.py`: Decoding and reconstruction of the original text.
